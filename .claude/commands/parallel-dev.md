Parallel development using git worktrees.

**Process:**
1. Create 3 parallel implementations:
   - Performance-focused
   - UX-focused
   - Maintainability-focused
2. Compare approaches
3. Select best or merge best parts
4. Cleanup worktrees

**Example:**
```
/parallel-dev "search optimization"
```
