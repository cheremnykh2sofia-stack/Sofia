Codebase health analysis with metrics and recommendations.

**Checks:**
- Code quality metrics (complexity, duplication)
- Architecture assessment
- Security vulnerabilities
- Performance issues
- Best practices compliance
- Dependency health

**Output:**
- Health score (0-100)
- Critical issues list
- Recommendations
- Quick wins

**Example:**
```
/analyze .
/analyze src/services/
```
